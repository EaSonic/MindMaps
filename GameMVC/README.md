# Logan's Games — MVC Show & Tell

Presentation: https://easonic.github.io/MindMaps/GameMVC/

Choose Driving, Earthquake or Tsunami. Teaching controls update a rule illustration and representative game screenshots. The links above the examples open the real games. The original Archify diagram and fill-in prompts are preserved in the expandable section.

`index.html` is self-contained: all screenshots and the interactive Archify map are embedded. It also opens offline; real-game links require internet access.

Edit `source/presentation-source.html`, then run `python3 source/build.py` from this directory. The builder uses the included original screenshots and checked MVC map. `architecture.json` is the editable Archify map specification; its output path is relative to the repository root.

The controls are teaching examples, not live connections to the original games.
